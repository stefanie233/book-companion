### 15. EPUB 切分

**结论**：LLM 识别标题模式 + 机械切分

**理由**：两步工作流

### 16. 导入分析环境

**结论**：机械算完 CSS 层叠+继承+em 链，给 agent **有效排版**与整本样张；不给裸 CSS 与统计量

**理由**：统计是「读」的代理，代理丢信息

### 17. 导入分析编排

**结论**：立论 → 证伪 → 机械校验 → 回炉；verifier 只拿结论不拿推理

**理由**：结构是三方作用后**剩下**的，不是一次成型的

### 18. 导入分析提示词

**结论**：教方法不教答案（禁书籍专属结论）；体裁优先于切分

**理由**：旧提示词背着窄门的答案，是路径依赖

### 19. 形态标签

**结论**：逐段 `«形态名»` 前缀**只在读时渲染**，绝不写回 book_chunks.content

**理由**：content 上建着 FTS 与指纹匹配，带标签会让搜索污染、批注 relink 全断

### 20. 字体族

**结论**：进 EffectiveStyle/describe/等价组差异标注，**不进 sig()**

**理由**：family 可继承会致组**合并**；通用族首项会致误拆

### 64. 重导复用主键

**结论**：同坐标 + 逐字节相同 → 复用旧 chunk 主键；`relink_chunks` 在 `register_chunk` 前自动跑

**理由**：换主键 = 图谱锚点集体悬空（实测 8/9 本交集为 0）
