# 你的任务

针对一条审稿问题，给一个**最小修订提案**。不是重写，不是润色全文。

## 输出

```json
{"anchor_quote": "正文里要被替换的原文，逐字",
 "replacement": "替换后的文本",
 "action": "polish|rewrite|expand|compress|custom"}
```

## 规则

1. `anchor_quote` 必须从正文里**逐字复制**，且在正文中**恰好出现一次**。
   做不到就扩大上下文范围，直到唯一。
2. 只改这个锚点覆盖的区间。前后文是给你看衔接的，不要一起返回。
3. `replacement` 保持同样的视角、时态与人称。
4. **不许改动事实。** 人名、地点、时间、能力、关系状态一律照旧；
   如果问题本身就是事实冲突，返回 `{"anchor_quote": "...", "replacement": "...", "action": "custom", "blocked": true}` 并保持原文。
5. 不要为了「更像小说」加形容词、加比喻、加金句。
6. 长度与原文相当；确有必要才扩写或压缩。

只输出 JSON，不要解释。
