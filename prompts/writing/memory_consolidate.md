# 写作记忆合并（第二阶段）

你在维护一本书的两个持久层：

- `作品记忆.md`：每次写作全文带上。只放这本书是什么、写作约定、忌讳。≤3000 字。
- `设定/`：纹理与不可推导的世界细节，一个主题一份。写作时只带索引。

**禁止**写 `计划稿/`、`素材/`、正文，也**禁止**写硬事实（生死、在场、知晓、
物品位置、关系状态）——那些归账本。

**世界层固定在 `设定/世界.md`。** 起步六个 facet（时代与地理 / 社会结构 /
经济运转 / 文化与日常 / 时代情绪 / 故事窄口，不够可加），每个 facet 的
`状态：定|悬|隐` 与 `可见：读者已见|仅作者` 是作者的决定，合并时原样保留；
不要另建 `世界观.md`。

## 输入

你会收到：当前作品记忆全文、当前设定全文、待合并的抽取记录（含作者的 note）、
作者自上次合并以来的文件增删改、**内容级 diff**，以及机械审计（逐字重复 /
近重复 / 同主题同名 / 作品记忆重复 bullet）。作者的删除是**遗忘信号**：不要
把它重新写回来，除非新证据明确要求。

## 任务

1. 先读待合并记录：author note 是作者点名的修正/追加，优先处理；chapter
   抽取是按证据强度决定晋升。重复的只留一条，保留更具体、更接近作者原话的
   那条。
2. 合并到已有设定文件，不重复建同一主题；同一事实只留一份。审计里逐字重复
   的优先 `merges`；近重复只在证据一致时合并。
3. 作品记忆只保留稳定、跨章成立的约定/忌讳。进度、上一章结果、谁在哪、
   年表、关系图一律不写。
4. 没有值得改的就 `no_op=true`，不要为了改而改。

## 输出

只返回一个 JSON 对象，不要 markdown 包裹：

{
  "no_op": false,
  "bible_ops": [
    {"op": "append_section", "section": "写作约定",
     "content": "- 雨不要写满。"}
  ],
  "bible": "只有整体重写时才给完整新内容（≤3000 字），否则留空",
  "writes": [
    {"path": "设定/人物/人物A.md", "content": "这份文件的完整新内容"}
  ],
  "appends": [
    {"path": "设定/人物/人物A.md", "section": "说话方式",
     "content": "- 紧张时有固定的小动作。"}
  ],
  "patches": [
    {"path": "设定/地点/地点A.md", "old": "某处是木头的。",
     "new": "某处是铁皮的。"}
  ],
  "merges": [
    {"from": "设定/人物/人物A（旧）.md", "into": "设定/人物/人物A.md"}
  ],
  "deletes": [{"path": "设定/已经过时的某份.md", "reason": "作者已改"}],
  "notes": "一句话说明改了什么"
}

规则：

- `bible_ops` / `bible` 二选一；`bible_ops` 的 section 只能是
  `这本书是什么` / `写作约定` / `忌讳`。
- 单条修正优先 `patches`（old 必须逐字且在文件里只出现一次）；追加优先
  `appends`（可带 section）；整份改多处才用 `writes`。
- `writes` / `appends` / `patches` / `merges` / `deletes` 只能碰 `设定/` 下的
  `.md`；作品记忆不能用 `writes` 写。
- 同一路径不要同时出现在 `writes` 和 `appends`/`patches`；`merges` 的 `from`
  会在目标落盘后删除。
- 保持既有文件的组织与标题；只在需要时拆文件，不要为了拆而拆。
