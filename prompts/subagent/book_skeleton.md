# 骨架提取：先认清这个世界的成员

你在读一本书的正文，这次只做一件事：**认清书里有哪些人、他们之间是什么关系**。

不要讲情节，不要记「谁在第几章说了什么」。那些事后面有人做，而且比你在这个
位置上做得更细。你做的是一件**全局**的事：一本书里谁是同一个人的不同叫法，
谁是谁的姐姐、母亲、朋友、仇人 —— 这些关系散落在几十个场景里，**只有同时看着
整本书的人才拼得出来**。这是你的价值。

## 一、实体：只收撑得住整本书的

一个名字值得成为实体，当且仅当它在书里有**跨场景的存在**：反复出现，或者虽然
出现不多但改变了别人的命运。

- 书里**有人物**（小说、传记、回忆录）→ 人物优先：有名字、有台词、有动机的人。
- 书里**没有连续的人物**（论说、科普、史论）→ 实体是**概念、学派、机构、作品**
  本身。这时不要硬找「主角」，也不要把作者当成主角（除非书里在讲他自己）。
- 地点、组织、作品、概念 —— 只有当它在书里**起作用**（有人去那里、受它影响、
  为它做事、被它论证）时才收。泛泛出现的背景词不收。
- 一个只出现过一次、没有名字、只做了一件事（端茶、开门）的人，**不收**。

### 名字

- `name` 用正文里**最完整的那一种写法**，没有全称就用最常用的那个。
  中文名不要替它补姓，译名不要自己音译 —— 正文里没出现过的写法不是名字。
- **光有称谓的要加限定词。** 正文里只叫「母亲」「舅舅」「女仆」的人，`name`
  写成「沈砚的母亲」这种**带名字**的形式，把「母亲」放进 `aliases`。
  否则书里两个母亲会被合成一个人 —— 而这是表格里最贵的一种错。
  （实测：写成抽象的「某某的母亲」，模型会照抄「母亲」两个字的裸称谓，
  一本书里出现两个「母亲」节点。）
- `aliases` 收正文里**真实出现过的**其它叫法：昵称、称谓（「表姐」「舅舅」）、
  全名、简称。**不要收别的译本或别处的写法**。
- `identity` 一句话，**这个人一出场就成立**的那种：「药铺学徒，祁元朗的关门
  弟子，做事缜密」；不要写成某个场景里的动作（「她在窗边哭泣」）。
- **不要写结局。** 死亡、远走、后来的婚嫁、最后的变故 —— 一个字都不要进
  `identity`。这句话会直接进角色卡，而角色卡**不按章节过滤**：写了结局，
  读者在第一章就看见了。后来的事由观察和关系去记，它们带章节锚点，会被
  剧透门挡住。

## 二、关系：只有这些词

关系用下面这张表里的词。**不许自创** —— 自创的关系词在库里就是一串孤立的
字符串，查询和合并都用不上它。两个名字之间如果有一种以上关系，写多条。

| 类别 | 词 | 含义 |
|---|---|---|
| 亲缘 | `parent_of` `sibling_of` `spouse_of` `relative_of` `adopted_by` | 父母 / 兄弟姐妹 / 配偶 / 其它亲属 / 被收养 |
| 社会 | `friend_of` `ally_of` `rival_of` `enemy_of` `mentor_of` `student_of` `colleague_of` `servant_of` `patron_of` | 朋友 / 同盟 / 竞争 / 敌对 / 师长 / 学生 / 同侪 / 仆从 / 庇护 |
| 情感 | `loves` `hates` `desires` `fears` `trusts` `distrusts` `admires` `despises` `envies` `pities` | 爱 / 恨 / 欲求 / 畏惧 / 信任 / 怀疑 / 敬慕 / 轻蔑 / 嫉妒 / 怜悯 |
| 行动 | `protects` `harms` `betrays` `deceives` `obeys` `commands` `rescues` `abandons` `pursues` `avoids` | 保护 / 伤害 / 背叛 / 欺骗 / 服从 / 支配 / 搭救 / 抛弃 / 追求 / 回避 |
| 交流 | `writes_to` `speaks_with` `confides_in` `advises` `reproaches` `accuses` `thanks` `preaches` | 通信 / 交谈 / 倾诉 / 劝告 / 责备 / 指控 / 致谢 |
| 空间 | `lives_in` `visits` `travels_to` `born_in` `dies_in` | 居住 / 到访 / 远行 / 生于 / 卒于 |
| 人生 | `marries` `elopes_with` `cares_for` | 结婚 / 私奔 / 照料 |
| 作为 | `studies_at` `works_at` `serves_in` `authored` `owns` `plays` | 就读 / 任职 / 服役 / 著作 / 持有 / 演奏 |

**方向很重要。** `parent_of` 的箭头从父母指向子女；`loves` 从爱的那一方指向
被爱的那一方。兄弟、朋友、夫妻这类对称关系，按正文里先出现的一方写就行。

**拿不准就不写。** 少一条关系只是少一条；写错一条会让人物的画像挂在别人身上。

### 写完先查一遍名册

挑出书里最重要的一批人（主角、对手、反复出现的人），**按这本书是什么书**
过一遍清单。**清单是按体裁分的，不是每本都全查** —— 一本论说类的书里没有
人，硬套亲缘清单只会逼出编造。

**叙事类（小说、传记、回忆录、史书里的人物）—— 逐人问：**

1. 血亲：谁生了他？他生了谁？谁是兄弟姐妹？→ `parent_of` / `sibling_of`
2. 姻亲与伴侣：和谁结婚、和谁在一起？→ `spouse_of` / `marries`
3. 养亲与其它亲属：收养、继亲、叔伯姑姨祖辈？→ `adopted_by` / `relative_of`
4. 非血亲但定身分的：师从谁？服侍谁？和谁同盟、与谁敌对？→
   `mentor_of` / `student_of` / `servant_of` / `patron_of` / `ally_of` /
   `rival_of` / `enemy_of` / `colleague_of`

**这一步不能省，而且必须逐人逐个问题地查。** 实测同一本书跑两遍，亲缘边会
随机漏掉三到六条 —— 不是书上没写，是没系统地查一遍。漏掉的形状很固定：
三姐妹里少一条、三兄妹里少一条、夫妻只有一方。查到正文没有明说的，跳过，
不要猜。

**论说 / 科普 / 随笔类 —— 清单换成：**

- 谁提出了什么主张、谁反驳了谁？（`mentor_of` / `student_of` / `rival_of`
  能覆盖一部分）
- 哪些实体属于哪个更大的东西？（**从属不在词表里** —— 别硬塞，写成实体的
  `identity`）
- 这种情况下 `relations` 可以是**空的**。空是对的，编一条假的比空着糟得多。

**自检只有一句：这个关系是正文自己说的，还是我替它归的类？** 是后者就别写。

## 三、每条都要有原文

`evidence` 填**正文里逐字的一小段**，能支撑这条关系或这个身份。不要改写、不要
拼接。找不到逐字原文的，就不要写这条。

`chapter` 填这段原文所在的章号 —— 正文里每章开头有 `=== chapter_index: N ===`
的标记，照抄那个 N。

## 输出

严格 JSON，无额外文本：

```json
{
  "entities": [
    {"name": "沈砚", "kind": "character",
     "aliases": ["沈师弟", "小沈"],
     "identity": "柳记药铺的学徒，祁元朗的关门弟子，做事缜密",
     "chapter": 2, "evidence": "沈砚在柜上抓药，手比谁都稳。"},
    {"name": "祁元朗", "kind": "character",
     "aliases": ["祁先生", "师父"],
     "identity": "柳记药铺的坐堂大夫", "chapter": 2,
     "evidence": "祁先生坐在里间，隔着帘子听外头报药名。"},
    {"name": "沈荷", "kind": "character",
     "aliases": ["阿荷", "姐姐"],
     "identity": "沈砚的姐姐，在城南替人浆洗", "chapter": 3,
     "evidence": "阿荷每月十五来看他一回。"}
  ],
  "relations": [
    {"source": "沈砚", "kind": "sibling_of", "target": "沈荷",
     "chapter": 3, "evidence": "阿荷每月十五来看他一回。", "detail": "姐弟"},
    {"source": "沈砚", "kind": "student_of", "target": "祁元朗",
     "chapter": 2, "evidence": "沈砚在柜上抓药，手比谁都稳。", "detail": "师徒"},
    {"source": "沈砚", "kind": "works_at", "target": "柳记药铺",

```

上面是虚构的示例，只用来看**形状** —— 换一本书，人物、关系、章号全都不是你该

`kind`（实体的）只用：`character` / `place` / `organization` / `work` / `concept` / `object`。
